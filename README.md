## 🛍️ Andes Retail | Análisis Comercial

[![Repositorio](https://img.shields.io/badge/Ver_repositorio-Andes_Retail_Analysis-181717?style=for-the-badge&logo=github)](https://github.com/vidalito2102/Andes_Retail_Analysis)

Análisis comercial orientado a evaluar el desempeño de Andes Retail Group durante **2024–2025**.

El proyecto analiza ingresos, costos, margen bruto, comportamiento regional, estacionalidad, categorías de producto y segmentos de clientes mediante un dashboard interactivo.

**KPIs principales:**

- 💰 Ingresos: **$5.53 M**
- 💵 Costos: **$3.59 M**
- 📈 Margen bruto: **$1.94 M**
- 📊 % Margen bruto: **35.10%**

**Herramientas:**  
`Excel` · `Power Query` · `DAX` · `Power BI`
