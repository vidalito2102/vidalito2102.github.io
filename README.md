# Vidal — Portafolio de Analista de Datos

Sitio personal construido con HTML y CSS para GitHub Pages.

## Estructura

- `index.html` — página principal
- `style.css` — estilos y diseño responsive
- `assets/perfil.jpg` — fotografía de perfil (agregar manualmente)
- `assets/` — imágenes futuras de proyectos

## Antes de publicar

1. Cambia `TU_CORREO@ejemplo.com` por tu correo.
2. Cambia los enlaces `#` de los proyectos por las URLs de tus repositorios.
3. Cambia el enlace de LinkedIn por tu perfil.
4. Agrega tu foto como `assets/perfil.jpg`.
5. Si vidalito2102 de GitHub no es `vidal`, crea el repositorio con el nombre exacto `vidalito2102.github.io`.

## Publicación

GitHub Pages permite publicar archivos estáticos como HTML, CSS y JavaScript desde un repositorio. Para un sitio personal, el repositorio debe seguir el formato `<usuario>.github.io`.

Después de subir los archivos:

`Settings → Pages → Build and deployment → Source → Deploy from a branch`

Selecciona `main` y `/ (root)` y guarda.
